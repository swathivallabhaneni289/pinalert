Fake server rules
  • Code: 123456 works. Any other code is wrong. Five wrong in a row lock the code until a new one is sent.
  • Sign in: priya@example.com with pinalert-demo. An account you create here works too. Five wrong tries lock an email. An email starting with locked is locked at once.
  • Old link account: an email starting with old opens step 4 as an old account (name and home area filled in).
  • Passwords: a common one (password, 12345678, qwerty123) or the email itself is refused.
  • Usernames: ravi, ravi.k, anjali.r and kiran_77 are taken. police, p0lice, police.help, ndma, imd, govt, admin and similar are kept for official use. rude.name is refused on save. justtaken shows available, then is taken on save.
  • Home area search: Benz Circle, Indiranagar, Andheri, T Nagar, Salt Lake, Banjara Hills, Gayathri Nagar, Koramangala.
  • Not simulated: the real server sends no usable code to an address that has no account or already has a password. The screen is the same, and here code 123456 works for any address.
