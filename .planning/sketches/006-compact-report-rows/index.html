Sketch 006: report rows on the laptop

Only the report rows change. The map, the page and the words stay as they are. The tab strip (Active, Disputed, Past) is the one you asked for in place of the checkbox. Click a row to select it. All names and numbers are sample data.

Map, unchanged

    What each size takes out of the row

    • Out of the row in all three: the Confirm, Dispute and Mark resolved buttons (the opened report already has them, as on the phone), the clock line, the divider and the chevron. Both counters, the severity word, the category, the time and the state word stay.
    • A, phone card: exactly the card the phone already has, so it is the cheapest to build and the page looks the same on every screen.
    • B, tight card: a category badge on the left, the title in the body size, and one facts line. About two thirds of A.
    • C, one line: severity word, title and counters on one line. Click a row and it opens in place for the category, time and state word. The most rows on a screen, the title is cut with an ellipsis until the row is opened.

    How big a row is today

    A report row on the laptop is 323px tall (300px for the quieter ones), so an 800px screen shows two rows and a bit. The dashed box is that height.
