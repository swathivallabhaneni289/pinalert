What to look for

  • Is it obvious this is the same report you just tapped, only larger: same badge, same trust block, same three actions?
  • Does the thread read as a plain list, oldest first, with nothing that looks like a social feed?
  • Post a comment at the bottom. It joins the end of the thread and the count updates.
  • Open the phone size first. The desktop view only changes the width, or in B adds the map beside the panel.

The Reporter label marks the report author's own replies in words. No identities, emails or avatars are shown. The composer is not in your brief: it is included so the thread is complete, and it is one label, one box and one button. Thread text is sample data.
