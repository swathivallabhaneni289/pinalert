# Profile tab in the bar, My activity moves into Settings, Public profile switch

## Why

7.1 UAT test 7, 2026-11-17, owner on the iPhone simulator, in Settings:
- "I don't think the followers and following list should be on the settings. Even view my
  profile in settings is unnecessary."
- "I think the profile, view my profile should like have more specific way to like actually
  display it, because I think it's one of the major feature in this project."
- "my activity page basically is showing what the profile should show right?" then
  "whatever we have in my activity page can be shifted to the setting by keeping one section
  for it", then "yes build it" to this shape:
  - Bottom bar: Nearby, Official alerts, **Profile**, + Report (the laptop top bar the same).
  - Settings: a new section for My activity with its five rows, each opening that list, Back
    returning to Settings.
  - The bell's "See all updates" still opens your updates.
  - View my profile, Following and Followers leave Settings (all three are on your profile).
- "we can maybe form the wording better when it comes to let others follow me ... use a
  different sentence or a word": the switch becomes **Public profile** with the line
  **Anyone can see your profile and follow you.**

## What changes

### 1. The main places (internal/api/handlers/nav.go and the person page)

- `mainNavItems`: the third place becomes `{Key: NavProfile, Label: "Profile", Href: "/me",
  Icon: "user"}` (a new key `NavProfile = "profile"`). Nearby and Official alerts and the
  + Report item are unchanged. The laptop top bar draws the same list, so it gets Profile too.
  The laptop account menu (My profile, Settings, Log out) is unchanged.
- Your own profile page (`PersonPage`, `profile.IsSelf`) marks Profile current, with the own
  title and no back arrow (it is a main place now, like Nearby). Someone else's profile, and
  the not found and load failed states, are unchanged (no place current, back arrow to /).
- `/me` keeps going on to `/u/<username>`.
- The Demo is unchanged: its bar keeps Nearby, Official alerts and My activity at
  /demo/activity (the Demo has no profile). Build its list separately so it does not change.

### 2. The My activity page (/profile, auth.go profile handler, profile.html.tmpl)

- It is no longer a main place: no bar item is current on it (like Settings).
- Its phone top bar: on the list (no part) the title stays "My activity" with a back arrow
  to /settings; on a part screen the title is the part name and the back arrow goes to
  /settings (not to the list), because the parts are now opened from Settings.
- Everything on the page itself (heading, hub, parts, record card, the bell's
  `/profile?part=updates`, old bookmarks and aliases) is unchanged.

### 3. Settings (web/templates/settings.html.tmpl, settings.go, settings JS)

- A new first section, before Notifications, built like the other sections (same
  `place-section` markup, intro with an h2 `place-section__title`, a `place-box`, the same
  laptop grid): title **My activity**, five link rows in the hub's order with the hub's part
  names (Updates, Posted, Confirmed, Disputed, Ended nearby, or whatever names the hub shows
  today), each `<a class="place-row" href="...">` with the label and a right chevron like the
  removed View my profile row, but shown on both sizes. Each href is the same part address
  the hub uses (take it from the same builder, do not hand write it). No icons, no counts,
  no sub lines.
- Remove the rows `settings-following-row`, `settings-followers-row` and
  `settings-view-profile-row`, and only the code that served them (their openers and count
  writes in the settings scripts, `FollowingCount` and `FollowersCount` in the view model if
  nothing else uses them, the sizeOnlyNamed entry). The shared people list window stays: it
  still serves Muted people, Blocked people and the profile page's Followers and Following.
- The switch row `settings-profile-row`: label **Public profile**, and under it
  `<span class="place-row__sub">Anyone can see your profile and follow you.</span>` in the
  same pattern as the Notifications row's sub line. Its behaviour and the Turn off box are
  unchanged.
- The section title "People and reports" stays.

### 4. Copy that names the old switch

- welcome.html.tmpl step 4 Name help: "Shown only if you let others follow you." becomes
  "Shown only if your profile is public."
- legal_body.html.tmpl: the two sentences that name "Let others follow me" (about lines 107
  and 123) name **Public profile** instead; change nothing else in them. ("in Settings" stays
  true: the switch is still in Settings.)
- Grep templates, scripts and service copy for any other on screen text that names "Let
  others follow me", "View my profile", or tells the person to find My activity in the bar,
  and update it the same way. Code comments that describe the old layout may be amended with
  a dated note in the file's style.
