## Phase Goal

A visitor can submit a location-tagged emergency report and see it alongside other nearby reports
on a live map, without creating an account.

> **User-story format not locked.** ROADMAP.md's `**Goal:**` line states an actor and a capability
> but no `so that` outcome, so it does not satisfy the three-slot MVP user-story form. Reproduced
> verbatim above; the planner must not invent the missing clause. Run `/gsd mvp-phase 1` to lock a
> canonical story if the strict form is wanted.

<objective>
Turn 01-UI-SPEC.md from a table of values into an executable stylesheet: the full token layer
(spacing, typography, surfaces, the traffic-light severity palette, the age ramp, the focus ring)
in both light and dark, plus every shared component and layout class the three later frontend plans
consume — and the nine committed category glyphs.

This plan is the **visual contract** for wave 4. Plans 01-05 (modal) and 01-06 (feed list) run in
parallel and each own only their own stylesheet; if either has to come back and add a missing
custom property to `main.css`, that parallelism collapses into a merge conflict. So `main.css` must
emit the complete token set now — including tokens this plan renders nothing with, such as
`--color-age-stale`, without which plan 01-06's `color-mix()` age ramp (D-17) is undefined.

Decisions realised here: D-10 (neutral-utility base, colour reserved for severity), D-11
(traffic-light severity mapping), D-12 (white glyph on a solid colour-coded circular badge, badge
colour resolved to severity per UI-SPEC), D-13 (dark mode from Phase 1 via CSS variables, a
distinct palette rather than an inversion), D-16 (list-row left-border accent + tinted background),
D-17 (age fade as desaturation toward gray, not opacity), and the layout containers for D-06
(wide-screen split view) and D-07 (narrow-screen map-default with toggle).

Purpose: every later frontend plan reads values from here instead of inventing them.
Output: `main.css` (complete), two placeholder stylesheets, nine category SVGs.
</objective>
