## Pattern Assignments

### `internal/auth/code.go` (utility, transform) and `internal/auth/password.go`

**Analog:** `internal/auth/token.go` (48 lines, deleted last).

**Core pattern** (token.go 33-48): crypto/rand only, return the error instead of panicking (it runs inside a request), a deterministic hash helper next to the generator.
```go
func GenerateToken() (raw string, hash string, err error) {
	buf := make([]byte, tokenBytes)
	if _, err := rand.Read(buf); err != nil {
		return "", "", err
	}
	raw = base64.RawURLEncoding.EncodeToString(buf)
	return raw, HashToken(raw), nil
}
```
Copy the shape for `NewCode()` (`rand.Int(rand.Reader, big.NewInt(1_000_000))`, `%06d`) and `CodeHash(key, purpose, email, code)` (HMAC-SHA256 hex, per RESEARCH design section 2). Keep the long doc comment style that names the threat ids. `password.go` has no analog for the PHC encoder (see No Analog Found); copy only the "constants at top, doc comment names the threat" style.

### `internal/service/credentials.go` (service, request-response + CRUD)

**Analog:** `internal/service/auth.go` (`RequestLink` 170-215, `VerifyTokenAndBind` 278-399). Leave `AuthService` alone (it also owns the Activity reads, about 45 constructor call sites).

**Constructor and option pattern** (auth.go 121-165): `type AuthOption func(*AuthService)`, `WithClock`, `NewAuthService(q AuthQuerier, m mailer.Mailer, baseURL string, opts ...AuthOption)` with `now: time.Now`. Give `CredentialService` the same: a consumer-side querier interface, `WithClock`, `WithHasher`, `WithCodeKey`.

**Cooldown claim, refused claim maps to ErrRateLimited** (auth.go 175-198, keep verbatim for both code kinds):
```go
email, err := normalizeEmail(rawEmail)
...
now := s.now()
if _, err := s.q.ClaimEmailCooldown(ctx, sqlcgen.ClaimEmailCooldownParams{
	Email:          email,
	RequestedAt:    now,
	CooldownCutoff: now.Add(-ResendCooldown),
}); err != nil {
	if errors.Is(err, pgx.ErrNoRows) {
		return "", ErrRateLimited
	}
	// No address in the message: the handler logs this error, and no
	// email may reach the server log (WR-S03).
	return "", fmt.Errorf("service: claiming email cooldown: %w", err)
}
```
Persist before send, a granted claim commits before the insert and the send so a failed send still consumes the cooldown (auth.go 164-169 doc). A mailer failure is wrapped (`fmt.Errorf("service: sending ...: %w", err)`) so the handler logs detail and returns a generic 500.

**Binding pattern to reuse, minus the rotate-or-not decision** (auth.go 366-396): `InsertAccount`, `GetAccountByEmail`, then `BindSessionAccount` with a guarded upsert and a refusal path when `n == 0`. For 7.1 the rule is simpler: always draw `mgr.NewID()` and bind that (RESEARCH Pattern 3), so `GetSessionBinding`, `ErrSessionNeedsFreshID` and the rotate logic go away with the link flow.
```go
n, err := s.q.BindSessionAccount(ctx, sqlcgen.BindSessionAccountParams{
	SessionID: boundID,
	AccountID: &account.ID,
})
if err != nil {
	return "", "", "", fmt.Errorf("service: binding session to account: %w", err)
}
```
**Reset revoke:** call `SessionService.LogOutAllDevices(ctx, accountID)` (`internal/service/sessions.go` 69-84), which revokes sessions and deletes push subscriptions. Do not write a new revoke query.

**Error vocabulary to reuse:** `ErrRateLimited`, `ValidationError{Field, Message}` (used by handlers with `errors.As`), `normalizeEmail`/`NormalizeEmail` (auth.go 799-811).

### `internal/store/queries/auth_codes.sql` and `auth_throttles.sql` (sqlc, atomic UPDATE)

**Analog:** `internal/store/queries/magic_link_tokens.sql` lines 17-30 and `email_cooldowns.sql` lines 1-16.

**Atomic consume, never read then write** (magic_link_tokens.sql 25-30):
```sql
UPDATE magic_link_tokens
SET used_at = now()
WHERE token_hash = sqlc.arg(token_hash)
  AND used_at IS NULL
  AND expires_at > now()
RETURNING email;
```
`BumpAuthCodeAttempt` and `ConsumeAuthCode` in RESEARCH Pattern 2 follow this exactly (no rows means refused, surfaced as `pgx.ErrNoRows`).

**Guard on DO UPDATE so a refused claim writes nothing** (email_cooldowns.sql 11-16): copy for `auth_throttles` locked attempts, so a refused attempt cannot extend the lock.
```sql
INSERT INTO email_cooldowns (email, last_requested_at)
VALUES (sqlc.arg(email), sqlc.arg(requested_at))
ON CONFLICT (email) DO UPDATE
SET last_requested_at = EXCLUDED.last_requested_at
WHERE email_cooldowns.last_requested_at <= sqlc.arg(cooldown_cutoff)
RETURNING last_requested_at;
```
Keep `-- name:` header and the long comment explaining the race, as both files do.

## Shared Patterns

### No email in a page address or log (D-05, WR-S03)

**Source:** `magic_link_tokens.sql` 17-30, `email_cooldowns.sql` 1-16.
**Apply to:** code try counts, code consumption, per account sign in throttle.

**Apply to:** per device buckets, IP backstop only when `CLIENT_IP_HEADER` is set, username check and save. The per account wrong password budget lives in the DB table, not here.

### Session cookie writer
**Source:** `session.Manager.SetCookie` and `NewID`, used in `Verify` (auth.go 262-264) and `Logout` (`mgr.ClearCookie(w)`, 861-870).
**Apply to:** sign in, sign up confirmation. Set before any body write. When the request's old session was bound to a live account, also call `subs.DeleteForSession(r.Context(), oldID)` as `Logout` does (auth.go 860-866).

### Dated amendment notes on pinned tests
**Source:** `TestAccessGateExemptRoutes` doc comment, `gate_test.go` 307-317 ("Amended 2026-10-18 by Phase 3.3 plan 04 ...").

### Copy rules
**Apply to:** all user visible strings. No em or en dashes (`TestUserVisibleCopyUsesPlainPunctuation*`). Actions are real buttons, never underlined links. Silent notifications only. Confirm boxes reuse `.logout-confirm`. Plain words for the wrong credentials sentence: "Email or password is wrong."
