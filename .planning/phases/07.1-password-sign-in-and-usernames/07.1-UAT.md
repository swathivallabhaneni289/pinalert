### 1. The sign in page
expected: Create account and Sign in sit side by side, the globe is whole, nothing scrolls sideways, light and dark.
result: issue
reported: "earth is taking long time to actually load." After a reload: "it's fast now"
severity: minor
note: The log shows why. On the first visit after the server starts, the server fetches the 30 Earth pictures it needs from NASA GIBS, about 0.4 to 0.9 seconds each, so the globe shows about 3 to 4 seconds after the page. The server then keeps them in memory and the browser keeps them for a month, so a reload is fast. On a free host that sleeps when idle the first visitor after each wake waits again. Proposed fix: fetch the 85 pictures in the background as soon as the server starts. Kept in memory only, nothing written to disk or the repo.
