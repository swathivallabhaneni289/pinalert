Built from the owner's locked sketch 008 (locked 2026-10-17), `08-CONTEXT.md` (D-01 to D-20), `08-RESEARCH.md` and the built 03.4, 03.2 and 07.1 contracts. ## Surface 2: Laptop placement (default A), kept apart so option B is a one section swap

### 2a. What happens (default A)

1. A pin tap opens the popup bubble over the map **exactly as built**. The only new thing in it is the **Open report** row at the bottom (Surface 8).
2. Pressing Open report closes the bubble and opens the report in the **panel**: the panel takes the Nearby list column's place (`.pane--list` is hidden while a report is open, as the phone already does with `html[data-popup-open]`), every pin stays on the map, and the chosen pin stays grown. The address becomes `/?report=ID` with one history entry (built behaviour).
3. While the panel is open, tapping **another pin switches the panel to that report** (no bubble opens), the same as the phone strip's behaviour; the history entry is replaced, not added.
4. **Back** (top left of the panel) closes the report and shows the list again; so do Escape (when focus is not in the composer, see Interaction), the browser's back, and a tap on empty map. The pin stays chosen; the bubble does not reopen.
5. **A tap on a report row in the Nearby list** keeps its built laptop behaviour (the map centres on the pin and the bubble opens), so the laptop list is not disturbed (D-18); the full report is one more tap away through the bubble's **Open report** row, which meets SC1 through "the popup's footer". Under option B a row tap opens the panel directly instead. Listed under "Defaults to confirm at the viewing session".

## Surface 4: "What happened so far" (SC2)

A short history built by the server from the vote log. It never names a voter, never says where anyone was and never shows an account. It is closed copy, no free text.

**Structure.** An ordered list (`ol`), one row per event, oldest at the top, newest at the bottom:

|------|-------|

| Mark | a 12px dot, `--color-text-muted` (neutral), `--color-tone-good` (confirmed, resolved, shown to everyone) or `--color-tone-bad` (disputed, marked Disputed), with a 2px `--color-border` connector running down to the next row (none on the last). `aria-hidden`. |
| Text | the server's sentence, `--color-text`. |

## Interaction and Accessibility

- **Focus order (page):** the top row (Back), Confirm, Dispute or Mark resolved, Share, the trust block button, Stop updates, Flag, then each comment in order: Reply, Like, Delete or Flag, View replies (and, in an open thread, each reply's controls), Show more comments, Cancel reply, the box, Post. Laptop popup: the Open report row is last.
- **Escape order:** the Delete box, the Flag dialog, the Share window (each closes itself and returns focus to what opened it); then, outside the box, the report closes (the built behaviour). **In the box, Escape never closes the report**: with a reply target it cancels the reply, otherwise it does nothing, so typed words are never lost.
- **Names:** every icon button has a name (Close, Cancel reply, Like with its count, Back to the list); Reply, Delete and Flag are named as in P8-C6; the Open report row's name includes its count. The disc is `aria-hidden`; the username is read in the head line. Times use `<time datetime>`.
- **Structure:** the Comments list is a `ul` under an `h2`; replies are a nested `ul`; View replies has `aria-expanded` and `aria-controls`; the timeline is an `ol`; the public page has one `h1` and its box is a `dl`.
- **State is never colour alone:** a liked thumb is filled and weight 600; a reporter has the word tag as well as the disc; a timeline dot has its sentence; a disabled Post has `aria-disabled` and the same shape; the status chips are words.
- **Live regions:** one visually hidden `role="status"` per page for "Comment posted.", "Comment deleted." and the counter thresholds; `role="alert"` on `.inline-error`; `#share-status` for the Share window. Nothing announces new comments from other people or each keystroke.
- **Reduced motion:** the Share sheet slide, the chevron on the trust block and any hover colour change are instant under `prefers-reduced-motion: reduce`. No scroll triggered animation exists.
- **Text size:** controls wrap or grow; nothing is cut to a fixed height; no horizontal page scroll at 320px and 200 percent text (the meta line wraps, usernames wrap anywhere, the link in the share card wraps anywhere).
- **Forced colours:** see Color.
- **Keyboard:** every control reachable; Enter posts and Shift with Enter adds a line; the thumb is a toggle button (Space and Enter).
- **Typing safety:** the report host sits outside the map container, so Leaflet's keyboard handling is not engaged; the box still stops `keydown` from reaching the map handlers.
- **Touch targets** (every one 44 by 44 or larger, listed so `TestNewControlsMeetTouchTarget` names them): Share, WhatsApp, Copy link, Share X, Try again (each block), Reply, Like, Delete, Flag, View replies, Hide replies, Show more comments, Cancel reply X, the box, Post, Open report row, Back, the Delete box buttons (built), Sign in to see more, Disclaimer, Policy.
