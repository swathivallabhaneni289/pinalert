# Phase 1.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Go stdlib `testing` (no third-party test framework — matches Phase 1 throughout) |
| **Config file** | none — `go test` reads `go.mod` directly; CI config lives in `.github/workflows/ci.yml` |
| **Quick run command** | `go test ./internal/... ./web/...` (DB-dependent tests self-skip via `t.Skip` when `DATABASE_URL` is unset, per `testutil.NewTestDB`'s existing behavior) |
| **Full suite command** | `DATABASE_URL=postgres://postgres:postgres@localhost:5432/pinalert_test?sslmode=disable go test -v -p 1 ./...` (mirrors `.github/workflows/ci.yml` exactly — `-p 1` required, packages share one Postgres instance and truncate it) |
| **Estimated runtime** | ~15s (quick), ~90s (full, real Postgres) |

---

## Sampling Rate

- **After every task commit:** Run `go test ./internal/... ./web/...`
- **After every plan wave:** Run `DATABASE_URL=... go test -v -p 1 ./...` (full suite, real Postgres)
- **Before `/gsd-verify-work`:** Full suite must be green, plus the manual verification below
- **Max feedback latency:** ~90 seconds
