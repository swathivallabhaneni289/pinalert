Gap-closure plan `01.1-08` (wave 7) was executed. This pass independently re-derived the fix from primary sources — it did **not** trust `01.1-08-SUMMARY.md`'s own claims — and confirms **the gap is genuinely closed**:

1. **Read `internal/api/router.go` and `internal/ratelimit/perip.go` directly.** `middleware.RealIP` is gone from both files (`grep -c` returns 0 in both, comments included). 2. **Read `internal/service/auth.go` and the new `internal/store/queries/email_cooldowns.sql`/generated code directly.** The cooldown is one statement: `INSERT INTO email_cooldowns ... ON CONFLICT (email) DO UPDATE SET last_requested_at = EXCLUDED.last_requested_at WHERE email_cooldowns.last_requested_at <= $3 RETURNING last_requested_at`. The guard lives on the `DO UPDATE`, so a refused claim performs no write; the table's `email TEXT PRIMARY KEY` is what serialises concurrent claims via Postgres's own conflict handling. This is genuinely one atomic statement, not a read followed by a write — `LatestTokenForEmail` (the old recency read) is confirmed absent from every file in the codebase (`grep -rn "LatestTokenForEmail" internal/` → no matches).

   - `TestRequestLinkLimiterIgnoresSpoofedProxyHeaders` (`internal/api`, real router) — PASS. Observed live: five 200s then one 429 across six requests, each with a distinct forged `X-Forwarded-For` and a distinct email.
