Decisions made at planning (record them in the SUMMARY):
- P-1 "Confirmed before" means: at some point in the report's vote history ConfirmedByPeople was true for the standing votes of that moment. It is replayed with the existing code: walk the log in order, keep each account's latest row per vote kind (what CurrentVotesForReports would have answered then), build the tally with BuildVoteTally, ask Resolve with the report's current meta, and test ConfirmedByPeople with the active view. This is exact for votes, needs no new state, and gives neither a false yes when disputes came first nor a false no when the confirming vote was the person's own.
