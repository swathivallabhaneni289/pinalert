# Phase 3.3 Plan 08: Subscription service and routes Summary

**A signed in device can register, check and remove its push subscription through three gated, per account limited, strict JSON routes; the endpoint only ever travels in a request body and is never returned, logged or put in an error, and every page can be given the VAPID public key.**

## What was built

- `internal/service/pushsubs.go`: `PushSubsQuerier` (the six queries, `var _ PushSubsQuerier = (*sqlcgen.Queries)(nil)`), `PushSubscriptionService`, `NewPushSubscriptionService(q, policy, opts...)`, `WithPushSubsClock`, `PushSubscriptionInput`, the three message constants. `Register` checks the endpoint through `EndpointPolicy.Check` (unknown host gives `ValidationError{endpoint, PushServiceUnsupportedMessage}`, anything else malformed gives `PushSubscriptionInvalidMessage`) and the keys through `push.CheckKeys` (field `keys`) before any query, upserts with the host Check returned, then trims to `PushDevicesPerAccount` (8). A failed upsert does not trim. An empty session id is a plain error. Database errors are reduced to their SQLSTATE by `scrubStoreError`, because a driver error detail can hold the offending values.
- `internal/api/handlers/push.go`: `RegisterPushSubscription(svc, pushKey, limiter)` (204, 503 when the key is empty), `PushSubscriptionStatus(svc, limiter)` (200 `{registered}`), `UnregisterPushSubscription(svc, limiter)` (204). All three read the account from `account.FromContext`, charge a limiter keyed by the account id, require `application/json` (415, a charset parameter is fine), cap the body at `maxPushBodyBytes = 4096` (413 from `MaxBytesReader`), refuse unknown fields and trailing data (400), and set `Cache-Control: no-store`. Log lines hold the handler name, the account id and the scrubbed error.
- `PageConfig.PushPublicKey` added; the router reads it from `deps.Page.PushPublicKey`, so setting it once in `cmd/server/main.go` (plan 11) switches both the pages and the 503 behaviour.
- `router.go`: `pushSubs` built next to `accounts`; constants `pushWriteBurst = 5`, `pushWriteEvery = time.Minute`, `pushStatusBurst = 10`, `pushStatusEvery = 6s`; three POST routes in the gated group.
- `make swag` ran with the installed swag binary; the three paths are in `docs/`, the diff is additions only. Swagger examples are plain placeholder words, not key material. `TestSwaggerSpecCoversRoutes` now covers the three paths and their 401.
