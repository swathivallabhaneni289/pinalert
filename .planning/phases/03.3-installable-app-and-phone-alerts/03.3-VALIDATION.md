# Phase 03.3: Validation Strategy

> Per-phase validation contract for feedback sampling during execution. Built from `03.3-RESEARCH.md`, section "Validation Architecture"; the planner fills the per-task map.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Go `testing` (unit tests run with `-short`, which skips DB tests), `internal/testutil.NewTestDB` for DB tests, `node --test` with `vm` sandboxes for JS |
| **Config file** | none beyond `Makefile` and `.github/workflows/ci.yml` (`go vet ./...`, Go tests, `node --test web/*.mjs`) |
| **Quick run command** | `env -u DATABASE_URL go test ./internal/push/ ./internal/service/ ./internal/api/... ./web/ -short -count=1 && node --test web/pwa_sw_test.mjs web/pwa_client_test.mjs` |
| **Full suite command** | `env -i PATH="$PATH" HOME="$HOME" DATABASE_URL=postgres://localhost:5432/p33_NN?sslmode=disable go test ./... -p 1 -count=1 -v` on a disposable `p33_NN` database per plan (create if absent, refuse if it exists, drop after; never `pinalert`, `pinalert_test` or `p34_uat`), plus `node --test web/*.mjs` and `go vet ./...` |
| **Estimated runtime** | quick about 60 seconds; full about 6 to 10 minutes |

---

## Sampling Rate

- **After every task commit:** the quick command for the touched packages.
- **After every plan wave:** the full suite on a disposable `p33_NN` database with zero `--- SKIP` lines (DB tests skip without `DATABASE_URL`, and a skipped test proves nothing), plus `node --test web/*.mjs` and `go vet ./...`.
- **Before `/gsd-verify-work`:** full suite green, then the owner's device checks.
- **Max feedback latency:** 120 seconds for the quick command.
