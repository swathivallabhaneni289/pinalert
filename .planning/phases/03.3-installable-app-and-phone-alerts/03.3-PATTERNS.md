## Pattern Assignments

### `internal/service/pushworker.go` (worker, lease/claim batch)

**Analog:** `internal/service/modworker.go`

**Constants and querier interface** (lines 14-56): named constants with a comment each, a small `WorkerQuerier` interface, and a compile-time assertion.
```go
const (
	ModerationSweepInterval = 30 * time.Second
	ModerationLeaseSeconds = 60
	ModerationBatchLimit = 5
	ModerationBackoffBase = 30 * time.Second
	ModerationBackoffCap = time.Hour
	ModerationBackoffMaxShift = 7
	ModerationWorkerCallTimeout = 8 * time.Second
	CheckErrorTransient = "transient" // last_error holds only a class word, never report text
)
type WorkerQuerier interface {
	ClaimDueModerationChecks(ctx context.Context, arg sqlcgen.ClaimDueModerationChecksParams) ([]sqlcgen.ClaimDueModerationChecksRow, error)
	...
}
var _ WorkerQuerier = (*sqlcgen.Queries)(nil)
```
**Options, clock and jitter seams** (lines 98-146): `type WorkerOption func(*ModerationWorker)`, `WithWorkerClock`, `WithWorkerJitter`, `WithSweepInterval`; constructor loops options and skips nil.
**Backoff** (lines 148-172): `min(base << clamp(attempts), cap) * factor`, raised to Retry-After. Copy for push 429/5xx; factor is `0.5 + jitter()`.
**Run loop** (lines 174-198): sweep once at boot (host cold starts), then `time.NewTicker`; `sweepAndLog` logs only when `ctx.Err() == nil`.
**SweepOnce** (lines 200-221): claim batch, loop rows, break on `ctx.Err()`, `errors.Join` the per-row errors.
**Logging rule:** log only numeric ids, attempt, class word, status, wait. Never the endpoint (it is a secret capability URL) or notification text.
**Wiring** (`cmd/server/main.go` 340-345):
```go
moderationWorker := service.NewModerationWorker(queries, screener)
go moderationWorker.Run(context.Background())
```
Add the push worker next to it with the same comment style.

### `internal/store/queries/push.sql` (claim query)

SET lease_until = now() + sqlc.arg(lease_seconds)::int * interval '1 second', attempts = attempts + 1 ... RETURNING`. Keep the comment explaining why a MATERIALIZED CTE, and filter on the database clock (`next_attempt_at <= now()`, `lease_until IS NULL OR lease_until < now()`, report not expired). ## Shared Patterns

### Gate and session
**Source:** `internal/api/router.go` exempt list (400-440) and gated group (444+); `account.FromContext(r.Context())` at the top of every handler (me.go, welcome.go).
**Apply to:** all new routes. Public only: manifest, sw.js, icons.

### Lease, claim, backoff, no secrets in logs
**Source:** `internal/service/modworker.go`.
**Apply to:** push worker. Endpoint URLs and payloads never logged.

### Server authored copy, one file, no dashes
**Source:** `moderationcopy.go` / `ratecopy.go` with their tests.
**Apply to:** `pushcopy.go`, UI strings in step 5 and Settings (UI-SPEC copy).

### Resolver gate
**Source:** `Resolve` + `ConfirmedByPeople` (confirmed.go 32-50) + `MayNotifyAboutReport` (3.2 plan). Apply to dispatcher only; SQL stays blind to visibility.

### Asset versioning
**Source:** `AssetVersion` field on every view model (welcome.go line 38) rendered as `?v={{.AssetVersion}}`. Apply to every new template include; `/sw.js` and the manifest are not versioned by query string, so serve with `no-cache`.

### Frontend rules
**Source:** `web/js_sinks_contract_test.go`, memory rules: no images in repo (icons rendered at startup by Go `image/png`), no dashes in prose or code strings, phone first at 320/360/390.
