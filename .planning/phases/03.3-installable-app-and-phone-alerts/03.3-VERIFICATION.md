None. The gap of the first report (fading change note for a Provisional report breaking D-07) is closed, see Re-verification 2026-10-25. The suggested override in the first report was never applied and is dropped.

**Hidden and resolved change notes (checked against D-07): unchanged, info only, one owner question.**

- They cannot use `MayNotifyAboutReport`: `ViewOf` maps Hidden to the Disputed tab and Retracted to Resolved, so the predicate returns false for them by design and the two events UI-SPEC 3b requires could never be sent.
- They announce a report leaving the feed, to the person who already posted or voted on it, so they cannot promote an unconfirmed report.
- The worker sends each only while the resolver's current answer is exactly that state (`UpdateHidden` needs `Vis == Hidden`, `UpdateResolved` needs `Vis == Retracted`).
- "Now confirmed" is stricter than Live: it needs `ConfirmedByPeople`, so a Critical report held Live through a dispute majority does not say confirmed.
- A report that was never Live can still produce "is now disputed", because 3.2's cursor takes the Provisional baseline and then sees Hidden. That matches what the feed shows and predates the fixes. The skeptic raised whether it fits D-07; it is now an owner question in the human verification list, not a gap.
