# Phase 3.3 Plan 04: Installable app assets Summary

The site now serves a web app manifest, a root scope service worker and an app mark drawn entirely in Go (SVG plus five PNGs from one set of 512 grid numbers), at ten exact public addresses that skip both the login gate and the session middleware.

## What was built

- `internal/appicon`: constants on the 512 grid, `SVG()`, `PNG(size, variant)` with 4 by 4 supersampling and no third party code, `Render()` giving the five PNGs with ETags. Deterministic. No image file exists in the repo.
- `web/static/js/sw.js`: one silent notification per push with exactly eight option keys (body, tag, renotify, silent, icon, badge, lang, data), the plain Pinalert notice for an empty or malformed payload, `safeTarget` accepting only `/?report=` plus 1 to 18 digits, tap focus then navigate or open window, subscription renewal on `pushsubscriptionchange`. No cache, no fetch handler.
- `internal/api/handlers/pwa.go`: manifest, worker, icon and SVG handlers, `Handler(path)` lookup, and `PWAPublicPaths` (the one list of ten addresses).
- `internal/api/router.go`: routes registered by ranging over `PWAPublicPaths`, `pwaSkipSet()`, `skipSessionFor` (GET only, empty RawPath, exact path), `application/manifest+json` compressible, NewRouter doc comment amended. router.go spells no PWA address.
