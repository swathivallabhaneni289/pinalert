## Phase Goal

**As a** person reading the feed during an emergency, **I want to** see how many different nearby people confirmed or disputed each report, and whether it is still current and its reporter reliable, **so that** a few accounts cannot make a weak report look well corroborated.

<objective>
Put the server's trust object on the wire. After this plan, every report in `GET /api/reports` and every vote response carry the same `trust` object. It holds the distinct confirming place count N (D-04), the distinct disputing place count M, their server capped numerals, and the three panel sentences. Both come from one handler mapper over the `Trust` value plan 03-05 builds in the service, so the feed and the vote response cannot drift (D-21). The OpenAPI spec documents the object, and a scoped name guard plus a runtime body test prove that no account id, email, voter cell or session id leaks. An end to end test also proves that concurrent votes from distinct places land as exactly that many places, which is roadmap criterion 1 of TRUST-05 observed on the wire.

Purpose: this is the second step of slice S2 "counters" in the outline's MVP framing. Plan 03-05 made the trust object exist inside the service. This plan exposes it. Plan 03-13 renders the counters on the feed row and popup, 03-14 adds the still current and reporter signals to this same object, and 03-15 shows it on the Activity page through this same mapper.

Increments, task by task (each ends at something a real end to end test observes):
- After Task 1: an end to end test reads `trust.confirmed_places` on the feed and on a vote response and they agree, on all four vote routes, for every viewer. Another end to end test watches N count places, not votes, through re-taps, shared places and a switch to dispute.
- After Task 2: the published API reference documents `trust`, a guard proves no identifier name appears in the guarded definitions, and a runtime test proves no identifier value or key appears in real response bodies.
- After Task 3: 24 concurrent voters from 12 places produce exactly 12 confirmed places under the race detector.

Output: new `internal/api/handlers/trust.go` and `internal/api/handlers/trust_e2e_test.go`; edited `reports.go`, `votes.go` and `swagger_test.go`; regenerated `docs/docs.go`, `docs/swagger.json` and `docs/swagger.yaml`.
</objective>
