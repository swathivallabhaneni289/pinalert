## Phase Goal

**As a** person reading the feed during an emergency, **I want to** see how many different nearby people confirmed or disputed each report, and whether it is still current and its reporter reliable, **so that** a few accounts cannot make a weak report look well corroborated.

<objective>
One vote control builder in `votes.js` serves the feed row, the map popup and the Activity page. After this plan every vote button carries an icon span and a label span (A12, A36), the Mark resolved confirmation is a named group whose question is read first and whose Cancel comes first and takes focus (A16, A63), every close path puts focus on a real control (A52), a cancel hook lets plan 03-13's Escape listener close an open confirmation, the vote block returns a hidden note node that both surfaces mount in reading order (A66, A8), the vote error keeps no child nodes (A73), and the Activity page Reopen is the same shared control (A64, A28, D-20). The Phase 2 re-tap contract stays (A34).

Purpose: this is the first step of the "Vote style" slice in the outline's MVP framing. Plan 03-11 styles exactly these spans and nodes, plan 03-18 fills the note, and plan 03-13 calls the cancel hook. Building the DOM contract once, here, keeps those three plans from each growing their own builder.

Increments, task by task (each ends at something a real user or a real contract test observes):
- After Task 1: a keyboard user who opens Mark resolved lands on Cancel inside a group named "Mark this report resolved?", and closing it by Cancel, by an error, by a pending answer or by the report leaving the feed puts focus on a real control instead of the page body.
- After Task 2: a screen reader still hears each vote button by its word alone (the icon span is hidden from it), the label survives every later write, and both the feed row and the popup mount the too far sentence slot between the buttons and the error, which a contract test proves.
- After Task 3: Reopen on the Activity page is the shared control from `votes.js`, with its icon span and label span, and its in flight and reset labels can no longer wipe the icon.

Output: edited `votes.js`, `feed.js`, `map.js`, `activity.js`; new `web/vote_controls_contract_test.go`.
</objective>
