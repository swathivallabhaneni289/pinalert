## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Testing against the owner's database | `testutil.NewTestDB` truncates whatever DATABASE_URL names. A past run wiped the owner's dev data in `pinalert_test`. An unset DATABASE_URL instead skips every DB test silently. | blocking | Create a fresh scratch database per run (for example `p3_uat`), point DATABASE_URL only at it, run with `-v` and count `--- SKIP`. Never `pinalert_test`, `pinalert`, `p3_view`. Never ports 8080 or 8090. |
| Closing Phase 3 with phase.complete | Phase 4 is already planned. `phase.complete` rewrites STATE.md to the next phase "Ready to plan" and `roadmap.update-plan-progress` ticks the phase Complete at 20 of 20 before verification. | blocking | After `phase uat-passed 03 --require-verification` says passed, edit the ROADMAP row and REQUIREMENTS (TRUST-05, TRUST-07) by hand and commit only those paths. |
| Committing with the commit verb | `gsd-tools query commit` commits everything staged, adds no trailer, and the working tree is shared with another session. | advisory | `git add -- <path>` then `git commit -m .. -m .. -m "Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>" -- <path>`. |
| Assuming Show disputed adds to the list | The Show disputed view REPLACES the default view (the two sets are disjoint, `ListableInFeed`). A wrong brief caused a fix that had to be reverted (9aaa925). | advisory | After a failed request with the flag changed, clear rows in both directions and show the error with Retry. |
| Trusting a fixer's own checks on trust critical JS | Independent skeptics found defects in 5 of 8, then 3 of 4 fixes that the fixers had reported as proven. | advisory | Run a read only skeptic workflow (two lenses per fix plus a weakened test auditor) and commit its findings. |
| Assuming Chrome is installed | Only Safari is installed. Test steps written for Chrome could not be followed. | advisory | Check which browsers and tools exist before writing steps. Chrome for Testing is in `~/Library/Caches/ms-playwright/chromium-1243/chrome-mac-arm64/` for DevTools checks (launch with its own `--user-data-dir`, not yet tried). |
| Judging a UI claim by eye | Said the reporter words sat beside the label when a wide popup still wrapped them. | advisory | Measure every surface, width and state (the same line check in the scratchpad, `same-line.js`) and look at screenshots in WebKit before claiming a layout. |
| Stale browser cache on the preview | The owner reviewed an old copy of the sketch and called a fixed layout wrong. | advisory | Serve the preview with `Cache-Control: no-store` (a python http.server subclass bound to 127.0.0.1 on 8799, repo root as directory). |
| Variants registered in two places | A new sketch variant must be added to index.html AND stage.html (script and stylesheet), or the card draws like another variant. | advisory | Check the stage page loads the variant script, then measure. |
| Parallel edits on one file | A repair agent edited the sketch while it was being changed by hand. | advisory | Make small exact replacements, re-measure afterwards, and check git status before committing. |

**Severity values:** `blocking` means the resuming agent must pass an understanding check; `advisory` is context only.
