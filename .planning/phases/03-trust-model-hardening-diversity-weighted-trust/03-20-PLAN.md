## Phase Goal

**As a** person reading the feed during an emergency, **I want to** see how many different nearby
people confirmed or disputed each report, and whether it is still current and its reporter reliable,
**so that** a few accounts cannot make a weak report look well corroborated.

This plan closes the phase. After it, a reader of `docs/TRUST-MODEL.md` can follow every rule from
the vote to the screen and trust that the document matches the code (a test fails the build when
they drift), the two earlier UI contracts send readers to the Phase 3 contract, the generated code
matches its sources, and the owner signs off the whole phase on a fresh database.
