## Phase Goal

**As a** first-time visitor, **I want to** land on a working map with real official alerts and a Demo I can try, **so that** I trust Pinalert before I post anything.

<objective>
Answer "which official alerts cover me, and can I trust that answer right now" in one gated JSON route that the Official alerts page (05-09), the Nearby banner (05-15) and the Demo (05-19) all draw from.

Purpose: ALERT-01 (the reader's district), ALERT-02 (issuer, issued, until, gone on expiry), ALERT-03 (banner only for Severe or Extreme in the reader's area), ALERT-04 (last checked and plain stale or unavailable), with D-06 to D-10 and D-16. The view is a pure function so the Demo can feed it sample alerts; the route also carries the lazy refresh, the first of the three triggers.
Output: the closed word tables, freshness, the pure view, the official service, the handler and route, the server wiring, end to end tests and regenerated API docs.
</objective>
