<objective>
**As a** person near an ongoing incident, **I want to** confirm or dispute another user's report **so that** reports lacking independent nearby corroboration lose visibility while well-corroborated ones stay trusted — and as a reporter or nearby confirmer, I want to mark a report resolved once it's no longer true, so the feed reflects what's actually happening right now.

This plan is **one slice** of that story: the pure decision logic. It ships the single
authoritative function that decides which of Hidden / Provisional / Live / Retracted a report is
in, given an already-loaded vote tally. Nothing user-clickable lands here — 02-05 is the first
user-clickable increment, and this plan exists so that click is provably correct rather than to
"lay a layer."

Purpose: TRUST-02 requires that a report's visibility state be **identical everywhere it is shown**
— feed, map, triage view, shareable card. The only way to guarantee that is for exactly one
function to decide it, and for that function to be provable in isolation. So this plan builds
`Resolve()` as a pure, DB-free function over plain Go values and proves every locked decision
about its behaviour with table-driven tests over fabricated tallies, before any HTTP handler,
SQL query or browser code exists to get it wrong.

The decision ladder this plan encodes, each rung citing the decision it implements:

- **D-07** — Retracted is a *distinct trigger*, fired only by explicit resolve marking, never by
  dispute volume and never folded into ordinary expiry. It is therefore checked **first**, ahead
  of every other rung, so a resolved report is never re-surfaced by confirm volume.
- **D-16 (amended 2026-09-15)** — a Retracted report is reopenable, and reopening is **exactly
  symmetric** with D-13's reporter-instant resolve. Two paths flip Retracted back to the live
  pipeline: the reporter's own standing reopen vote, which succeeds **instantly with no threshold**
  regardless of how the report came to be Retracted (their own instant resolve OR independent
  confirmers' agreement); or `IndependentAgreementThreshold` standing independent reopen cells from
  non-reporters. `VoteTally` therefore carries `ReporterReopened bool` mirroring `ReporterResolved`
  field-for-field, and `isRetracted()` is a symmetric expression with a reporter-instant term on
  **both** sides. (Amendment history: the original 2026-09-12 discuss session locked reopening as
  threshold-only with no carve-out; `02-RESEARCH.md` Open Question 1 flagged that asymmetry as
  needing explicit user confirmation, `gsd-plan-checker`'s 2026-09-15 pass caught that it had never
  been confirmed, and the user's answer reversed the reading. See `02-CONTEXT.md` D-16's amendment
  history — this is now locked, not open.)
- **D-06** — critical-severity and rescue-needed reports can **never** be Hidden by disputes. The
  bypass rung sits above the dispute rung, so no volume of disputes can suppress a possibly-real
  emergency behind a soft trust signal. The same rung also clears TRUST-04's Provisional gate
  (TRUST-04's own text: critical/rescue-needed reports publish at full visibility immediately,
  with no gate).
- **D-05** — Hidden fires when disputes *outnumber* confirms *past a threshold*: both a floor
  (`DisputeCells >= IndependentAgreementThreshold`, so a single dispute can never hide anything)
  **and** a strict majority (`DisputeCells > ConfirmCells`, so a bare tie does not hide either).
- **D-08** — Hidden is fully reversible. There is no unhide branch, no latched flag and no stored
  status column: the same function called again with a later tally in which confirms outweigh
  disputes simply returns Live or Provisional. Reversibility is a property of recomputing from
  current tallies, not a feature that had to be written.
- **D-09** — Provisional is emitted as a state distinct from Live (never folded into it), because
  02-06's dimmed **and** explicitly-labelled treatment needs a discrete state to key off. This
  plan owes D-09 exactly one thing: that the state exists and is reachable.
- **D-14** — one independence number, not three. `IndependentAgreementThreshold` is read by the
  Hidden floor, the Provisional gate, the confirmer-resolve threshold and the non-reporter reopen
  threshold. There is deliberately no second constant to keep in sync. The two reporter-instant
  paths (D-13, D-16 amended) sit outside this number entirely — they are booleans, not a
  threshold of 1.

Output: `internal/service/visibility.go` (types, constants, `Resolve()`) and
`internal/service/visibility_test.go` (the table-driven proof — the exact file
`02-VALIDATION.md` names as a Wave 0 gap).
