### `queries/accounts.sql` and `sessions.sql` (sqlc, CRUD)

**Analog:** `internal/store/queries/accounts.sql` (whole file, 2 queries) and `sessions.sql:17-23`.

```sql
-- name: GetAccountBySessionID :one
-- A session with a NULL account_id yields no row (pgx.ErrNoRows), which
-- callers must treat as "unverified", never as an error.

FROM sessions
JOIN accounts ON sessions.account_id = accounts.id

```

Add to `accounts.sql`: `-- name: AcceptTerms :exec` (`UPDATE accounts SET terms_agreed_at = COALESCE(terms_agreed_at, now()), terms_version = ... WHERE id = sqlc.arg(id)` for idempotence), `MarkFirstRunDone :exec`, `UpdateAccountProfile :exec`, `GetAccountProfile :one`. Always `sqlc.arg(name)` style, a leading comment per query. Extending the `SELECT` in `GetAccountBySessionID` changes the generated row struct; the only caller is `gate.go:84`.

**sqlc.yaml** (no change needed): `sql_package: "pgx/v5"`, `emit_pointers_for_null_types: true`, so the new nullable TEXT columns generate as `*string` and nullable TIMESTAMPTZ as `pgtype.Timestamptz` (only non-null timestamptz is overridden to `time.Time`). func ViewOf(v Visibility, expiresAt, now time.Time) FeedView {
	switch v {
	case VisibilityRetracted:
