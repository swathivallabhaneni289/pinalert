# Phase 3.4 Plan 37: The phone list sheet steps aside for an open report Summary

The list sheet now drops to short, is hidden under an open report detail, and returns to the position it had when the detail closes, for a row tap, a pin tap and a second report opened after the first.

## Commits

| Commit | What |
| ------ | ---- |
| 2bf43a9 | sheet.js observer, phone.css hide rule, feed.js pin guard, node and contract tests |

## What was found

In WebKit at 390x844 a row tap already dropped the sheet to short and the detail (z-index 1080) covered it. A pin tap did not: map.js never told the sheet, and feed.js even raised it to half. In the owner's simulator the half sheet showed over the report. The fix makes the sheet leave by itself for every opener and hides it so nothing of it can show.
