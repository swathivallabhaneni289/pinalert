# Phase 3.4 Plan 31: Legal text structure, Disagree box, step 3 wording Summary

The Disclaimer and Policy keep every approved word but now read as two separate parts with one level of section headings, the emergency numbers are a tidy card, Disagree shows a short box with Read again and Log out, and step 3's second button reads Type my location instead.

## What changed

**Task 1, legal text (commits 411ac4b test, 7c4deda feat).**
- `legal_body.html.tmpl`: only `<h2 id="disclaimer">` and `<h2 id="policy">` stay h2 (first element of each part, no class, so the pinned prefix and the reader's scroll target are untouched). All other 15 headings (17 with the contact address set) are h3, each wrapped with its content in `<section class="legal-section">`.
- `legal.css`: part titles 24px/600, section headings 18px/600 everywhere, each section has 24px space above, a hairline, then 24px padding; the Policy title adds a 2px rule and 48px space so the two parts read as two documents. Paragraph and list spacing is even (12px between blocks, 8px between list items, the last block of a section carries none). The glossary shows each term bold on its own line, the explanation under it, 16px between entries (terms that share an explanation sit 4px apart; the default 40px indent on explanations is removed).
- Numbers card: one grid row per number with a hairline between rows. The number is a bold (600) cell, the description beside it from 560px up (fixed 10rem column) and under it on narrower screens, the note under the description in normal weight and normal text colour at the label size, and a Call 112 button (`btn btn--primary`, 48px, 6px corners like the other buttons, not a pill). The `.legal-numbers` card rules and the forced-colors border are unchanged.

**Task 2, Disagree box (commits 6cd8017 test, bd18441 feat).**
- `welcome.html.tmpl`: a hidden `role="group"` box (id `welcome-disagree-message`, `tabindex="-1"`, named by its sentence) with the line "To move forward, you need to agree." and two buttons: Read again (`welcome-reread`) and Log out, which is a real `<form method="post" action="/auth/logout">`, the same form the person menu uses (ends at /login).
- `welcome.js`: Disagree shows the box, moves focus into it and scrolls it into view; it records nothing. Read again sets the text box `scrollTop = 0` and focuses it. Agree hides the box at once; any step change hides it. The sentence is no longer in the script (the template is its one source). The script puts no handler on Log out.
- `welcome.css`: reuses the `.welcome__notice` tint and corners, no outline, no new colours, buttons 48px in an equal two column grid (natural width on a laptop).

**Task 3, step 3 wording.** Button "Type my location instead"; the search it opens is labelled "Type your location" with the placeholder "For example: Koramangala, Bengaluru" (placeholder, as step 4's field does).
