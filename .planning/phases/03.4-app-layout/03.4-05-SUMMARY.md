- **Commit:** `056161f`

**2. [Rule 3 - Blocking] The full web suite had to be green at Task 1, so two token tests were touched there**
- **Found during:** Task 1 acceptance (`go test ./web` exits 0)
- **Issue:** `TestTopChromeGeometry` pinned `.disclaimer-bar` rules in chrome.css and `TestBarTokenFollowsTheRealBar` pinned the bar's min-height; both fail the moment the bar rules go, but the plan files them under Task 2.
- **Fix:** the chrome.css half of each was amended in Task 1 (`.notice-strip` rules, no rule uses the token as its own floor); the JS half and the token tests were rewritten in Task 2.
- **Commit:** `056161f`, `fb4c9f0`

**3. [Rule 3 - Blocking] phone.css lost `body > .theme-toggle` and its two `body:has(...)` guards**
- **Found during:** Task 3
- **Issue:** the plan said to keep the existing narrow rule and add one for the bar case. Once index and profile carry no floating toggle, `TestPhoneRuleHeadsMatchTheMarkup` fails because `body > .theme-toggle` matches nothing on the pages that load phone.css.
- **Fix:** the standalone `body > .theme-toggle` hide and the two `body:has(...) > .theme-toggle` guards were removed; `.app-topbar > .theme-toggle` joined the existing hide list. The floating toggle on the Low data view and the moderator screen is still hidden below 900px by chrome.css (`body > .theme-toggle`). `map_tools`, `phone_layout` and `phone_markup` pins were amended with the D-08 note.
- **Commit:** `918310c`

**4. [Rule 1 - Design simplification] measureBar and watchBar differ from the plan's wording**
- **Issue:** the plan keeps the observer on "the strip's text box" and the reset of the written value. The strip's floor is `--space-2xl` and it never reads the token, so there is no grow-only hazard to reset and the strip itself can be observed (writing the token resizes the shells and the map, never the strip, so no ResizeObserver loop). Observing the strip itself also fires when the phone rule hides it (size becomes 0), so `0px` is written without waiting for a window resize.
- **Fix:** `measureBar` writes `0px` or the measured height with no `removeProperty`; `watchBar` observes `.notice-strip`. `TestBarTokenFollowsTheRealBar` was rewritten to match.
- **Commit:** `fb4c9f0`

**5. [Rule 1 - Rewrite] TestDisclaimerBarToken was rewritten, not amended in place**
- The three tier calc helpers (`p408BarCalc`, `p408ResolveBar`, `p408PxToken`) and the `math` and `strconv` imports were deleted with the tiers; the test now pins one declaration, `0px`, in `:root`, no tier, and no other stylesheet declaring it.

**6. [Minor] Line height 1.4 (the label token) instead of the mockup's 1.35** to keep the strip tokens only.
