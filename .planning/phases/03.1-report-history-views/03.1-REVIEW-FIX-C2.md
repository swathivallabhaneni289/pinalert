## Items 1 and 2: request log without reader data (bdbe556)

Files: `internal/api/router.go`, `internal/api/request_log_test.go`.

`middleware.Logger` is replaced by `requestLogger`, built on chi's `middleware.RequestLogger` with a custom `LogFormatter`. A line holds the request id, method, path without the query string, status, size and duration. Nothing from the query, body, cookies or headers is read. The path is written escaped (`r.URL.EscapedPath()`, the same path as `r.URL.Path` but encoded) so a crafted path with a newline cannot split a line. The request id and Recoverer stay as they were. `Deps.RequestLog` (a `*log.Logger`, nil means standard output) lets a test capture the log.

The test `TestRequestLogHoldsNoReaderData` sends `GET /api/geocode/place?q=SecretStreet&lat=13.0826&lon=80.2707` and `GET /api/reports?lat=13.0826&lon=80.2707&radius_km=5` through the real router, once anonymous (401) and once signed in. It asserts two lines for each path and that the whole log holds none of `SecretStreet`, `13.0826`, `80.2707`, `radius_km`, `q=`, `lat=`, `lon=`, `token=` or `?`.

Checked: the test passes with the new logger and fails when the router temporarily uses chi's default formatter (the log then shows the full query strings, including the verify token). The change was reverted before the commit. Items 1 and 2 share one commit because the test is the proof of the change.
