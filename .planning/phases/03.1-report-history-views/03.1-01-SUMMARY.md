# Phase 3.1 Plan 01: History view classifier, closure replay, history strings and Rescue coarsening Summary

Pure service functions every history surface will read: one tab classifier (ViewOf), a closure replay that says when and by whom a report was closed (ClosureOf), the server written history strings (BuildHistoryFacts) and one shared coarsening of a finished Rescue report (CoarsenFinishedRescue).

## Decisions made

- `ClosureOf` replays prefixes of the standing resolution rows (sorted by time then account id) through `BuildVoteTally` and `isRetracted`. The closure time is the last false to true flip, so a retraction that was lifted and later re-closed reports the later time (nothing latches).
- `ByPeople` is true when the full tally holds at least `IndependentAgreementThreshold` independent resolve cells; `ByReporter` is the reporter's standing resolve. Both can be true; `At` is whichever made the report Retracted first.
- `outcomeLabelText` returns "Expired" for a corroborated outcome with a confirmed count below one, which a real tally cannot produce; this keeps a count of zero from ever being printed.
- Tests build their own vote rows with `p31` prefixed helpers instead of reusing `p05VoteAt`, so this plan has no coupling to another plan's test helpers.

## Deviations from Plan

None to the code or the files. Two small notes:

- **TDD commit shape.** The plan is `type: tdd`, but the owner's standing rule is one commit per task, so each task commit holds the test and the implementation together. The RED state was observed locally for Task 1 (build failed on undefined `FeedView`) before the implementation was written. The separate `test(...)` then `feat(...)` commit sequence of the plan level TDD gate therefore does not appear in git history.
- **`go vet` suspect or.** The first draft of TestBuildHistoryFacts compared State against both the constant and the literal in one `||`; vet rejected it, so the test now compares against the literal only (the constants `HistoryStateResolved` and `HistoryStateExpired` are still used by `BuildHistoryFacts`).
