# Phase 3.1 Plan 04: History reads Summary

Three bounded, parameterised history reads (expired reports in the 7 day window, unexpired candidates that may be closed, one report by id for links) added beside the untouched NearbyReports, with no migration and proven on a real Postgres.

## What was built

- `internal/store/queries/history.sql`: `ExpiredReportsInWindow :many` (ordered by expires_at desc, id desc, limited by row_cap), `OpenReportsInArea :many` (strictly after the instant, nearest first, limited by row_cap) and `ReportForFocus :one` (by id, distance from the given centre, no expiry or area predicate). All return the twelve NearbyReports columns in the same order and never a session id, cell or account. One lettered comment block (a) to (f).
- `internal/store/sqlc/history.sql.go`: generated by `make sqlc`; it was the only generated file that changed (db.go and models.go untouched, no migration).
- `internal/store/history_test.go`: TestHistoryQuerySourceHasNoClockCall, TestHistoryCandidatesExpiredWindow, TestHistoryCandidatesNotFilledByLiveReports, TestHistoryCandidatesOpenSet, TestReportForFocusOutsideRadiusAndWindow, TestHistoryRowsOmitSessionID.
