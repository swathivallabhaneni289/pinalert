# Phase 3.1 Validation Strategy

> Per-phase validation contract for feedback sampling during execution. Built from the Validation Architecture section of `03.1-RESEARCH.md`.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Go `testing`; fake queriers for the service layer; real Postgres for store and handler end to end tests; static contract tests in `web/`; the Playwright browser harness at `~/code/pinalert-browser-checks` (outside the repo) |
| **Config file** | `Makefile` (`test`, `test-short`, `vet`, `sqlc`, `swag`), `sqlc.yaml`, `.planning/config.json` |
| **Quick run command** | `env -u DATABASE_URL go test ./internal/service/ ./web/ -count=1` |
| **Full suite command** | `env -i PATH="$PATH" HOME="$HOME" DATABASE_URL=postgres://localhost:5432/<disposable>?sslmode=disable go test ./... -p 1 -count=1 -v` after `make sqlc && make swag` |
| **Estimated runtime** | about 30 to 60 seconds for the full suite |

**Database rule for every plan, executor and checker:** create a throwaway database with a name made for that run (for example `p31_03`), never reuse a name that exists, run with `-p 1`, count `--- SKIP` lines (must be 0), drop only your own database afterwards. Never `pinalert`, `pinalert_test`, `p3_view` or `p_view_act`. macOS has no `timeout` command, so do not wrap runs in it.

---

## Sampling Rate

- **After every task commit:** the quick command for the touched package plus the named test, for example `env -u DATABASE_URL go test ./internal/service -run 'TestViewOf' -count=1`
- **After every plan wave:** `env -u DATABASE_URL go test ./internal/service ./web -count=1` and `go vet ./...`. After the server contract wave also `make sqlc && make swag`, then `git diff --stat docs internal/store/sqlc` to confirm the generated files match the committed ones, then the store and handler tests on a disposable database with `-p 1`.
- **Before `/gsd-verify-work`:** the full suite green on a disposable database, then the browser harness at 320, 360, 390 and 1280 wide in both themes (`bash ~/code/pinalert-browser-checks/run.sh`, its own `_auto` database and a free port, never 8080, 8090 or 8792 to 8794).
- **Max feedback latency:** 90 seconds per task
