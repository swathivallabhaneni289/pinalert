## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-31-49 | Information disclosure | XSS through place names | high | mitigate | names and full names are written with Pinalert.setText only; TestPlaceSearchScript forbids markup parsing sinks in map-tools.js |
| T-31-50 | Tampering | request building | medium | mitigate | q is encodeURIComponent'd, lat and lon are numbers from the store; the server re validates (plan 03) |
| T-31-51 | Denial of service | type ahead load on the geocoder | medium | mitigate | no request on input events, one request per submit, a second submit during a request is ignored, plus the server budget |
| T-31-52 | Information disclosure | filter and place persistence | low | mitigate | chip and place are never stored or written to the address (D-18), so nothing about a reader's area survives the visit |
| T-31-53 | Spoofing | stale search response | low | mitigate | AbortController and a sequence guard drop a response for an older query |
</threat_model>
