<objective>
Build the server side of the address search: a standalone `internal/geocode` package that
proxies one Nominatim `/search` query under a process-wide 1 request/second ceiling with a
compliant User-Agent (D-02), and the thin `internal/api/handlers` surface that validates the
query, allowlists the response, and maps every failure to the D-04 fallback message.

Purpose: 07-RESEARCH.md establishes that a browser cannot set a compliant `User-Agent` and
cannot enforce a global rate ceiling, so the geocoding call has to happen server side. This plan
is that server side, built and unit tested in isolation before anything is routed or wired.

Output: `internal/geocode/client.go` + `client_test.go`, `internal/api/handlers/geocode.go` +
`geocode_test.go`. No route registration and no client-side code (those are plans 07-03 and
07-04).
</objective>
