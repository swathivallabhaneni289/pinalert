modal map, an absolutely positioned suggestion container anchored to that input, and an inline
status line for D-04's no-match and unavailable messages. Extend the two standing contract tests

markup and the stacking/hidden-guard discipline right in its own plan, gated by the same contract
tests the rest of the frontend already lives under, keeps plan 07-04 free to be purely about
behavior.

ids asserted in `internal/api/handlers/page_test.go`, and two new CSS contract tests in
`web/css_contract_test.go`. No JavaScript (that is plan 07-04), so the three new elements are
inert after this plan.
