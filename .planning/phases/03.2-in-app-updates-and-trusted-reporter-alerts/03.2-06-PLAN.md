<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser cookie to server session | The cookie is a stateless signed id; only the server row can end it |
| sign in link to session binding | A clicked link binds whatever browser opened it |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.2-10 | Spoofing | stolen or copied cookie | high | mitigate | revoked_at on every session of the account, read by the one gate query; TestLogoutAllRevokesEverySession uses a copied cookie |
| T-03.2-11 | Tampering / Repudiation | VerifyTokenAndBind, BindSessionAccount | high | mitigate | Binding read before ConsumeToken; a revoked or deleted session bound to another account gets a fresh id; the guarded upsert refuses to move a bound row (zero rows); e2e proves the old row keeps its author |
| T-03.2-12 | Elevation | requireModerator | high | mitigate | The same filtered query; TestModeratorGateRefusesRevokedSession |
| T-03.2-15 | Tampering / Information disclosure | LoginGate done | medium | mitigate | Exact comparison against two fixed words; the raw value is never rendered; TestLoginDoneLineIsClosedList |
| T-03.2-09 | Tampering | POST /api/me/logout-all | medium | mitigate | Gated route, POST with a JSON body checked by decodeEmptyBody, SameSite Lax cookie (DEC-L); it only acts on the gate's own account |
| T-03.2-21 | Spoofing | plain Log out leaves the row bound | low | accept | DEC-K keeps authorship; orchestrator decision 6 keeps plain Log out as is; Log out of all devices is the documented way to end a copied cookie |
