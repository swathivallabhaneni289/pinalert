## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser to API | Every request comes from the browser; the account comes from the gate only |
| report text to another person's bell | report_line carries a reporter's words to followers |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.2-01 | Information disclosure | GET /api/updates | high | mitigate | Hand declared wire with no account, session, cell, coordinate or description field; report_line only through ReportFirstLine; TestUpdatesEndpointLeaksNothing walks the JSON |
| T-03.2-02 | Information disclosure / Tampering | updates, read, mutes | high | mitigate | acc.ID from account.FromContext only; no request names an account; TestMarkReadScopedToAccount and TestMuteRoutes |
| T-03.2-06 | Information disclosure | List rows, mute 404 | high | mitigate | Withheld reports read as unavailable rows or 404; the muted list shows no detail for them |
| T-03.2-08 | Tampering (stored XSS) | report_line, label | medium | mitigate | JSON only; the browser writes with textContent (plans 08, 12); html/template escapes the server rendered rows |
| T-03.2-09 | Tampering (CSRF) | POST read, mute, unmute | medium | mitigate | Gated POST with a strict JSON body and SameSite Lax (DEC-L); they only change the caller's own rows |
| T-03.2-16 | Denial of service | GET /api/updates | low | accept | One refresh per poll, bounded follow set (200) and three batched reads; the bell polls every 30 seconds only while visible (plan 08) |
| T-03.2-20 | Information disclosure | caching | low | mitigate | Cache-Control no-store on both personalised reads |
</threat_model>
