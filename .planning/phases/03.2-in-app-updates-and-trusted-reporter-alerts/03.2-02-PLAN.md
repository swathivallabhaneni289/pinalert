## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| resolver output to notification decision | An update or alert must never be decided from anything but Resolve's answer |
| report text to update row | Free text written by a reporter flows into another person's bell |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.2-05 | Tampering / Elevation | MayNotifyAboutReport | high | mitigate | One free function over Resolve's answer (Live and active); TestMayNotifyMatchesResolve compares it with Resolve over a severity, category, moderation and tally grid, so a second copy of the critical rule cannot appear |
| T-03.2-06 | Information disclosure | DecideUpdate, Withheld | high | mitigate | Withheld writes nothing; the TestWithheldInNoView assertion pins the predicate false for Withheld |
| T-03.2-01 | Information disclosure | ReportFirstLine | medium | mitigate | Only the first line, at most 160 runes, only through CoarsenFinishedRescue (no text for finished Rescue reports); default pending the owner's Q1 answer |
| T-03.2-03 | Denial of service | DecideUpdate | medium | mitigate | One event per report per hour; Provisional never moves the announced state, so a dispute flip flop collapses |
</threat_model>
