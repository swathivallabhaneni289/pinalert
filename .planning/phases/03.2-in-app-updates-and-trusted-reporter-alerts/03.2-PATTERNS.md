## Shared Patterns

### Account from the gate, never from the body
**Source:** `internal/api/handlers/flag.go:61-66`, `me.go:84-89`, `settings.go:54-59`
**Apply to:** every new handler (`updates.go`, `me.go` additions, `LogoutAll`)
Every handler resolves the verified account with `account.FromContext(r.Context())`, answers a bare 500 when absent, and passes `acc.ID` to the service. No request body or query names an account id.

### Strict small JSON bodies
**Source:** `flag.go:73-81`, `me.go:128-141`, `me.go:55-65` (`decodeEmptyBody`)
**Apply to:** every new POST and PATCH
`http.MaxBytesReader`, `DisallowUnknownFields`, one `writeFieldError(w, 400, "body", "Request body is missing or malformed.")`.

### Error mapping
**Source:** `flag.go:88-107`
**Apply to:** every new handler
Sentinel `errors.Is` to a status, `errors.As(err, &ve)` for `service.ValidationError`, otherwise log with `handlers: <Name>: %v` and a bare 500. Messages are service constants.

### Narrow querier plus service constructor that never dereferences
**Source:** `flag.go:80-97`, `profile.go:258-266`
**Apply to:** `UpdatesService`, alert settings, deletion service
Wire in `NewRouter` from `deps.Sessions`; no `Deps` literal change.

### The single visibility authority
**Source:** `visibility.go:268-299` (`Resolve`), `history.go:78-93` (`ViewOf`), `flag.go:133-140` (`ReportMeta` literal with `Moderation`)
**Apply to:** `updatesservice.go`, `updates.go`, anything that decides a state
Build `ReportMeta` with `Moderation` in the same function that calls `Resolve`; `Visibility == Live` already excludes `Withheld`; a withheld or missing report reads as not found / "This report is no longer available".

### Self contained page scripts, text through textContent
**Source:** `app-bar.js:1-18`, `account-menu.js:1-18`, `settings.js:1-26, 177-179`
**Apply to:** `updates.js`, `settings-alerts.js`
IIFE with `'use strict'`, quiet return when the markup is absent, no dependency on `app.js` globals, no markup strings. `mute.js` is the exception: like `flag.js` it runs only where `app.js` is loaded and uses `Pinalert.setText`, `Pinalert.relativeTime`, `Pinalert.CATEGORY_LABELS`.

### Windows close with the X only
**Source:** `settings.html.tmpl:100-138`, `settings.js:406-429`
**Apply to:** Muted reports, Log out of all devices, Delete my account windows

### No dashes in copy or comments
**Source:** `layout_rules_contract_test.go:466-488` (`phaseScripts`), `TestUserVisibleCopyUsesPlainPunctuation` for templates
**Apply to:** all new templates, scripts, and `updatescopy.go` (add a Go test); use the middle dot "·" as the separator as UI-SPEC says.

### Generated code
`make sqlc` after any `.sql` change; `make swag` after any new route or annotation; both outputs are committed. Migrations run by the owner as an explicit step, never on boot.
