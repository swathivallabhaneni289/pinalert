# Phase 3.2 Plan 14: Only Reliable reporters tick Summary

The Show menu on Nearby now has a fourth item, Only Reliable reporters, that filters the list and the pins to the reports the server marks `kept_by_reliable_filter`, with a filter line, a plain empty state, a status add on, and the word `reliable=1` kept in the page address by one small script.

## What was built

- **Store (app.js):** `state.reliable` (false at boot), `setReliable(on)` (assign only, answers whether the value changed, only a true boolean turns it on) and `reportKeptByReliable(report, on)`, a sibling placed right after `reportInShow`. With the tick off every report passes; with it on a report passes only when `report.kept_by_reliable_filter === true`. `visibleReports` keeps a report when both `reportInShow` and `reportKeptByReliable` agree, so the tick composes with All, Confirmed, Disputed and a category chip by AND. `reportInShow` is untouched; `confirmed_by_people` still appears once and `fetch(` twice in app.js.
- **reliable.js:** `window.PinalertReliable` with `readFromAddress` (exact `'1'` comparison), `set`, `toggle`, `renderLine`. `set` changes the store, drops a held report link, rewrites the address with one `replaceState` that sets or deletes only `reliable`, renders the line (sentence plus a `Show everyone` inline text button) and asks the store to redraw; no request is sent. At boot an address with `reliable=1` turns the tick on before the first draw. The `Show everyone` buttons (the line's and the empty state's) turn it off and return focus to the Show button.
- **Menu (show-menu.js, index.html.tmpl, feed.css):** a `div.show-menu__sep[role=separator]` hairline and a `button.show-menu__item[role=menuitemcheckbox][data-reliable]` with the check icon and the words, no second line. `items()` selects radios and the checkbox in document order, so arrow keys, Home and End reach it; Enter and click toggle it, close the menu and return focus to the Show button. `sync()` also keeps the checkbox in step, and runs on open so a tick turned off elsewhere shows correctly. Opening the menu still lands on the chosen radio.
- **Words and states (feed.js, index.html.tmpl):** `#reliable-line` (the filter line style), `#reliable-empty` ("No reports from Reliable reporters nearby" / "Critical reports still show. Reports from other people are left out." / "Show everyone"), the empty precedence chip, then the tick, then the Show choice's own, and `#feed-status` adds " Reliable reporters only." after the Show part.
- **Map (map.js):** `focusPinReport` returns null when the tick leaves the linked report out, so a linked report never draws a pin the list leaves out. map.js still makes no request.
- **CSS (feed.css):** `.show-menu__sep` (1px `--color-border`, `var(--space-xs) 0`), `[hidden]` guards for the new line and block, the loading rule and the button spacing for the new empty block. Tokens only.
