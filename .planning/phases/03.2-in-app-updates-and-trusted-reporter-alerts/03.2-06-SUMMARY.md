# Phase 3.2 Plan 06: Session revocation and the sign in rotation rule Summary

A revoked session or a deleted account is refused by the one gate query, and a revoked or deleted browser can never carry one account's history into another account's sign in: it gets a fresh session id and cookie instead, while the old row keeps its author.

## What was built

- **sessions.sql**: `GetAccountBySessionID` adds `AND sessions.revoked_at IS NULL AND accounts.deleted_at IS NULL`, so `requireVerifiedAccount` and `requireModerator` both refuse. `BindSessionAccount` is now `:execrows` with `ON CONFLICT ... DO UPDATE SET account_id, revoked_at = NULL WHERE sessions.account_id IS NULL OR sessions.account_id = EXCLUDED.account_id`. New `GetSessionBinding` (raw read, no revoked filter, returns revoked, account_deleted and the bound email) and `RevokeAccountSessions` (one statement per account). `make sqlc` changed only `sessions.sql.go`.
- **auth.go**: `VerifyTokenAndBind(ctx, sessionID, rawToken, newID)` returns the outcome, the email and the bound session id. It reads the binding before `ConsumeToken` and rotates when the session is bound, revoked or of a deleted account, and the link is for a different account (or the account is deleted). Same account revives the row. `VerifyToken` is a thin wrapper with nil `newID`. `ErrSessionNeedsFreshID` is returned before the link is consumed when a rotation is needed and none can be drawn.
- **sessions.go**: `SessionService.LogOutAllDevices` revokes every live session of one account and returns the count.
- **cookie.go / handlers/auth.go / router.go**: `Manager.SetCookie` writes the exact cookie `Middleware` writes (Middleware now calls it). `Verify(svc, mgr, tmpl, cfg)` sets the rotated cookie before writing the page. Plain Log out is untouched (DEC-K).
- **Tests**: 8 new unit tests in `auth_test.go`, 3 in `sessions_test.go`, `TestSetCookieMatchesMiddleware`, and six e2e tests in `session_revocation_e2e_test.go` (`TestRevokedSessionIsRefused`, `TestDeletedAccountSessionIsRefused`, `TestRevocationKeepsAuthorship`, `TestRevokedBrowserSignsInAgainAsSameEmail`, `TestRevokedBrowserSignsInAsDifferentEmailGetsFreshSession`, `TestModeratorGateRefusesRevokedSession`).
